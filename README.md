# Syncronim website

The production-ready static website lives in `outputs/`.

## Upload to GoDaddy Web Hosting (cPanel)

Upload and extract `outputs/syncronim-godaddy-upload.zip` in the domain's web-root directory. The resulting `index.html` must be at the web root, with the `projects/web/` folder alongside it.

## Main site files

- `outputs/index.html`
- `outputs/access-control.html`
- `outputs/networking.html`
- `outputs/cabling.html`
- `outputs/service-page.css`
- `outputs/projects/web/`
- `outputs/robots.txt`
- `outputs/sitemap.xml`

The contact form requires a form-service or inbox endpoint before it can deliver inquiries.
